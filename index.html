📥 Importer / Exporter un client

Télécharge le template (JSON ou Excel), remplis-le, puis importe-le pour créer le client automatiquement.

📋 Mode JSON :
1. Clique Copier le template · colle dans Notepad ou VS Code
2. Les champs marqués 🔒 AUTO dans le bloc _NOTICE sont gérés automatiquement — ne pas toucher
3. Remplace toutes les autres valeurs par les vraies infos du client
4. Va dans l'onglet ⬆️ Importer JSON · colle et valide
💡 Colle ici le JSON rempli. Le bloc _NOTICE sera ignoré automatiquement. Champs obligatoires : prenom, nom, profession.
📊 Mode Excel :
1. Clique Télécharger le template Excel — s'ouvre dans Excel ou Google Sheets
2. Chaque ligne = un champ (colonne A = section · B = champ · C = ta valeur · D = note d'aide)
3. Les lignes avec 🔒 AUTO en colonne D sont gérées automatiquement — ne pas modifier la colonne B, seulement la colonne C si tu veux
4. Ajoute des lignes comp_4_sigle, comp_4_titre... pour plus de compétences/expériences/projets
5. Enregistre en .xlsx · va dans l'onglet ⬆️ Importer Excel
✅ Sélectionne le fichier .xlsx rempli. Le formulaire se remplira automatiquement — tu pourras vérifier avant d'enregistrer.
